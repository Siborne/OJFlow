# OJFlow v1.5.0

这一版把日常训练最常用的几件事收进了一个更完整的工作流：管日程、收题目、写草稿、存模板、做 VP。

## 日程中心

- 新增独立日程页，集中查看今天、待进行、已完成和已过期日程。
- 工作台默认只显示今天的日程，也可以在设置中切换为“今天及未来”。
- 工作台日程卡增加高度限制和内部滚动，不再把旁边的做题树撑高。
- 新增“清理过期日程”，已完成日程不会被误删。
- 收藏比赛生成的日程、平台 Logo、比赛跳转和完成状态继续保留。

## 练习收件箱

- 改为更适合大量题目的双栏工作区，支持标题、来源和比赛搜索。
- 每道题新增独立代码草稿区、语言选择和练习笔记区，均保存在本机。
- 支持一键复制单组样例、全部样例和当前代码草稿。
- 支持手动添加题目：名称、链接、比赛来源和可选样例。
- 题目列表显示代码/笔记状态，切换题目时保留各自草稿。

## 代码模板库

- 新增模板库页面，支持标题、语言、分类和完整代码内容。
- 支持按标题、分类、内容搜索，并按语言和分类筛选。
- 一键复制模板内容。
- 支持创建、编辑和删除模板，数据跨重启保留。
- 设置中可配置全局快捷键，从其他应用直接呼出 OJFlow 并打开模板库。

## 虚拟参赛计时器

- 收藏比赛卡片新增 VP 计时入口。
- 支持开始、暂停、继续和重置。
- 计时状态持久化，关闭窗口后再次打开仍会继续。
- 适合因时间冲突错过比赛后，按原比赛时长进行虚拟参赛。

## 题库与桌面修复

- 修复牛客题库把 `/acm/problem/list` 误识别为题目“题库”的问题。
- 牛客和 QOJ 题目解析现在只接受带数字题号的详情页链接。
- Windows 托盘改用原生 `.ico` 图标，修复托盘有占位但图标不可见的问题。
- 比赛提醒提前时间改为 5/10/15/30/60 分钟选项。
- 自动刷新间隔继续使用下拉选项，不再要求手动输入。
