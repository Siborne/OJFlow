# OJFlow v1.5.1

这一版补上了日常训练的几个关键体验：代码编辑器、模板导出、快捷键自定义和恢复默认设置。

## 代码编辑器

- 练习收件箱代码草稿和模板库编辑器升级为 CodeMirror。
- 支持行号、语法高亮（C++ / Python / Java / Rust / JavaScript）、深色主题和括号匹配。
- 支持代码折叠和自动补全。

## 模板库

- 支持导出 Markdown，可按标题、语言、分类筛选导出内容。
- 可在设置中关闭代码预览，模板列表只用于选择和复制。
- 支持 CodeMirror 编辑器语法高亮。

## 快捷键

- 点击按钮后直接监听键盘组合设置快捷键。
- 新增开关控制快捷键启用/关闭。
- 再次按下呼出快捷键时会隐藏窗口。
- 快捷键呼出时可选择打开工作台或模板库。

## 设置

- 新增"恢复默认设置"，一键清空所有设置、收藏、日程、模板。
- 与"清除查询缓存"分离，不会误删用户数据。

## 下载

- Windows：NSIS `.exe`
- macOS：`.dmg` / `.zip`
- Linux：`.AppImage` / `.deb`
