# OJFlow v1.3.0

这一版把 OJFlow 从“多平台查询工具”升级为面向算法竞赛选手的完整数据工作台。

## 工作台与日程

- 全新 Bento 数据工作台，集中展示近期比赛、Rating、解题数、算法主题分布和日程。
- 新增可持久化日程，支持创建、完成、恢复待办。
- 收藏比赛会与日程联动：关注比赛自动生成日程，取消关注时同步移除对应自动日程。
- 比赛查询支持 1、7、15、30 天窗口切换。

## 比赛与题库

- 聚合 Codeforces、AtCoder、LeetCode、洛谷、牛客、蓝桥云课、VJudge、HDU、POJ、QOJ 等平台数据。
- 比赛页支持今日、明日、本周、全部视图，以及平台筛选、缓存状态和实时刷新。
- 题库覆盖 Codeforces、AtCoder、力扣、洛谷、牛客和 QOJ。
- 新增 76+ 中英算法标签字典，支持中文/英文搜索、别名归一化和标签筛选。
- 中英文切换会同步覆盖导航、页面、筛选器和状态信息。

## 界面与个性化

- 提供简洁模式和完整模式，功能入口、信息密度和侧栏展示会随模式变化。
- 支持亮色、暗色和跟随系统。
- 提供海盐青、琥珀橙、苔原绿、莓果红、晴空蓝、暖沙金和墨夜黑 7 套强调色。
- 提供玻璃拟态、平铺、云雾和粘土 4 种界面质感。
- 自绘无边框窗口控制按钮，支持最小化、最大化/还原和关闭。
- 支持关闭到托盘、直接退出和开机自启设置。

## 数据与可靠性

- Rating 和解题数查询结果持久化到本地 SQLite，重启后保留查询上下文。
- 比赛、Rating 和解题数使用缓存优先策略；单平台失败不会阻塞其他平台。
- 设置、收藏、日程和账号信息使用本地持久化存储。
- 新增更新检查、下载与服务端/网络错误分类。

## 工程与发布

- 建立完整 CI：类型检查、ESLint、Prettier、单测、真实 Electron E2E 和生产构建。
- 主分支每次推送自动构建 Windows、macOS、Linux 安装包，Artifacts 保留 14 天。
- 推送 `v*` tag 自动创建正式 GitHub Release 并上传三平台安装包。
- 官网已部署到 https://siborne.top/OJFlow/。
